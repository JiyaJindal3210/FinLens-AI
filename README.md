# 💰 FinLens AI

> Understand why you spend, not just where you spend.

## 📖 About

FinLens AI is an AI-powered Personal Financial Behaviour Coach that helps users track spending, analyze financial habits, detect unusual transactions, and provide intelligent insights for better financial decision-making.

## 🚀 Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI Service
- FastAPI
- Python
- Scikit-learn
- Pandas
- NumPy
